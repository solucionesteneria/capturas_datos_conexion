Comandos de GIT para subir imágenes 
sobre los datos de la conexión:
 
Paso 1. Dentro de la carpeta 
"IMAGENES_DATOS_DE_CONEXION", 
hacer click derecho y 
seleccionar "open git bash here", 
una vez que se abra la ventana 
escribir los siguientes comandos 
linea por linea

Paso 2. Escribir los siguientes comandos
uno por uno


git pull

git add .

git commit -m "Agregando nuevas imagenes"

git push
